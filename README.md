# Phoebe's Room

AI 辅助儿童与青少年进行学科知识点强化训练的学习空间，目标使用周期贯穿小学到高中。

## 当前阶段

**MVP 范围已确认，实现计划已起草。** 未获明确开发许可前不进入业务功能开发。

MVP 摘要：家庭自用 · 二年级数学+英语 · SwiftUI iPad · 先 TestFlight · 选择/填空/应用题 + 拼读/听力 · 点选+输入/手写 · 星级 · 家长页 · 题库+AI 相似题 · 人设「爸爸&朋友」。
