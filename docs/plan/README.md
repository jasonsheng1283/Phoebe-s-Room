# 实现计划目录

大改动 / 新功能 / 重构的实现计划放在本目录。

## 命名

- 格式：`YYYYMMDD_plan.md`
- 同日多个计划：`YYYYMMDD_plan_<topic>.md`

## 何时需要写计划

- 改动影响面较大
- 新功能
- 重构
- 在 Plan 模式下讨论并确认的改动

小修复、文案微调、纯文档勘误等**不强制**写计划。

## 计划文档建议结构

1. 背景与目标
2. 已确认结论（链到 discussions / PRD）
3. 改动范围（文件 / 模块列表）
4. 不改动范围
5. 实现步骤
6. 风险与回滚
7. 验收标准
8. 状态（Draft / Approved / In Progress / Done）
