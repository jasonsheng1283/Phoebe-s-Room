## 1. 背景与目标

搭建 iPad 端 Phoebe's Room（家庭自用）：小学二年级数学 + 英语；做题+解析；题库+AI 相似题；三入口；星级掌握度；家长页；先 TestFlight。

## 2. 已确认结论

（略，见历史版本与 BACKGROUND）客户端 **SwiftUI**；先 TestFlight；题型/作答/星级/家长页已确认。

## 3. 技术栈

| 层 | 选型 |
|----|------|
| 客户端 | SwiftUI（iPadOS），源码在 `ios/PhoebeRoom/` |
| 手写 | PencilKit + 文本确认（无 OCR） |
| 音频 | AVSpeechSynthesizer（TTS） |
| 后端 | FastAPI + SQLite（`backend/`） |
| 内容 | `content/*.json` |
| AI | 本地相似题变式默认；可选云端 LLM（`LLM_API_KEY`） |
