## 1. 背景与目标

搭建 iPad 端 Phoebe's Room（家庭自用）：小学二年级数学 + 英语；做题+解析；题库+AI 相似题；三入口；星级掌握度；家长页；先 TestFlight。

**本计划在获得明确开发许可前不执行代码实现。**

## 2. 已确认结论

| 维度 | 结论 |
|------|------|
| 对象 | 家庭自用 |
| 年级 / 学科 | 二年级；数学、英语 |
| 场景 | 课后巩固、薄弱专项、日常习惯 |
| 设备 / 发布 | iPad；先 TestFlight，再 App Store |
| 题型 | 数学：选择、填空、应用题；英语：单词拼读、听力 |
| 作答 | 点选为主 + 输入 / 手写 |
| 掌握度 | 星级 |
| 家长 | MVP 含家长进度视图 |
| 内容 | 题库为主 + AI 相似题检查；知识点；不绑教材 |
| AI | 做题为主 + 解析；人设「爸爸 & 朋友」；云端 API |
| 客户端 | **SwiftUI** |

## 3. 技术栈（已确认客户端）

| 层 | 选型 | 说明 |
|----|------|------|
| 客户端 | **SwiftUI（iPadOS）** | Xcode 工程；触控 + Apple Pencil 手写 |
| 手写 | PencilKit（或等价封装） | 填空/应用题手写作答 |
| 音频 | AVFoundation + TTS/预置音频 | 英语听力与拼读示范 |
| 后端 | 轻量 API（**FastAPI 或 Node**，许可开工时二选一默认 FastAPI） | 题库、会话、掌握度、家长数据、**LLM 代理** |
| 数据 | PostgreSQL 或起步 SQLite/文件型 seed | 单家庭可先简 |
| AI | 云端 LLM API（Provider 待定） | 相似题、解析润色 |
| 秘钥 | 仅服务端 | 禁止打进 App |

## 4. 改动范围（许可后预计新建）

| 模块 | 预计内容 |
|------|----------|
| `ios/` 或 `PhoebeRoom/`（Xcode / SwiftUI） | iPad UI、三入口、做题流、解析、星级、家长页（门禁）、听写控件、手写控件 |
| `backend/` | API、题库、批改、相似题管道、LLM 代理 |
| `content/` | 二年级数学/英语知识点 + 种子题 + 听力音频清单 |
| `docs/*` | features / CHANGELOG / PITFALLS 同步 |
| 配置 | 服务端 `.env.example`、TestFlight / 隐私说明草稿 |

### 不改动范围

- 教师端、多租户、教材版本体系
- 自由聊天陪聊
- 完整间隔复习引擎、重激励 / 排行榜
- 应用题深度过程分（MVP 先关键答案可自动判）

## 5. 实现步骤（许可后）

### Phase A — 工程骨架

1. 初始化 SwiftUI iPad App + 后端骨架  
2. 打通健康检查与知识点列表拉取  
3. 单家庭简单身份（可先本地/固定家庭码）

### Phase B — 数学闭环优先

1. 导入数学知识点 + 种子题（选择 / 填空 / 应用题简化版）  
2. 点选 + 键盘输入作答 → 批改 → 解析（爸爸&朋友）  
3. 手写输入组件接入填空（识别策略：手写转文本 API 或先手写后确认，开工时定最小方案）

### Phase C — 英语拼读与听力

1. 单词拼读题模（听音/看词点选为主，跟读评分为增强）  
2. 听力题：播放音频 + 作答  
3. 解析与错误反馈

### Phase D — AI 相似题管道

1. 按题型结构化生成  
2. 自动检查（数学可验证性、音频题需绑定或 TTS 文案、年龄适宜）  
3. 入池 / 驳回日志

### Phase E — 三入口 + 星级 + 家长页

1. 巩固 / 薄弱 / 习惯选题策略  
2. 知识点星级展示与更新  
3. 家长页（简单门禁 + 进度 / 薄弱 / 练习时长摘要）

### Phase F — TestFlight

1. 签名与 TestFlight 构建  
2. 隐私与儿童数据说明草稿  
3. 家庭内测反馈后再规划正式上架

## 6. 风险与回滚

| 风险 | 缓解 |
|------|------|
| 数学应用题 / AI 生成错误 | 种子锚定 + 自动验算；应用题 MVP 结构化作答 |
| 听力资源成本 | 优先 TTS；关键词预置真人音频可后补 |
| 手写识别不准 | 点选为主；手写提供「确认文本」纠错；或先支持键盘 |
| 拼读跟读评分复杂 | MVP 不做强制评分，先听选/拼选 |
| App Store 儿童合规 | 先 TestFlight；无广告；数据最小化；家长门禁 |
| 云端环境无完整 Xcode | 可先建目录、模型与后端；UI 在可构建环境/你本地 Xcode 联调——许可后评估执行环境 |

## 7. 验收标准

- 数学：选择、填空、应用题（简化）各至少一条完整「作答→解析」路径  
- 英语：拼读、听力各至少一条完整路径  
- 点选可用；输入可用；手写有最小可用路径（或明确降级说明并获你确认）  
- 三入口可达；星级可见可更新  
- 家长页有门禁且能看进度摘要  
- 相似题检查链路有日志  
- iPad 主布局儿童可读  
- 可产出 TestFlight 构建（或构建所需工程完整）  
- 双视角验收报告并请你确认
