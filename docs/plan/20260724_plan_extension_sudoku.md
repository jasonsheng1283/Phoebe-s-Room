# 计划：扩展入口 + 数独过关（二年级 4×4 起）

> 状态：已执行（待验收）  
> 日期：2026-07-24  
> 用户确认：1A / 2B / 3A / 4C / 5B / 6C / 7C / 8B；许可：2026-07-24

## 1. 目标

首页增加独立 **「头脑拓展」** 入口；搭建可扩展的「扩展活动」框架；首个活动为 **数独式过关**（符号可为形状/物品，不绑教材单元）。二年级从 **4×4** 起步，关卡程序生成、难度缓升；进度同步后端；交互以点选为主、可选拖放；文案先保持克制。

## 2. 复述结论

| 项 | 结论 |
|----|------|
| 入口 | 首页独立入口（与口语并列） |
| 架构 | 扩展活动框架 + 数独为 Activity #1 |
| 二年级起始 | 4×4（2×2 宫），4 种符号 |
| 主题 | 按关卡自动换皮肤（形状→水果→小动物…） |
| 进度 | 线性解锁 + **后端同步** |
| 关卡 | **程序生成**，无限关，难度曲线可配置 |
| 交互 | 点选填符为主；支持拖符号入格 |
| 人设文案 | 本期先少文案，纯玩法 |

> 长期：按年级配置起始规格（如三年级可从 6×6 起）。MVP 档案为二年级，先实现 grade=2 曲线。

## 3. 产品结构

```
首页 → 头脑拓展 → 活动列表（先只有「符号数独」）
                 → 选关 / 继续 → 棋盘玩法 → 校验过关 → 解锁下一关
```

- 不进入数学教材知识点树；可有独立 `extension` 进度，不与教材星级混算（除非以后另定）。
- 家长摘要：可选展示「拓展最高关卡」（最小：后端有字段，家长页一行）。

## 4. 数独规则（4×4）

- 盘面 4×4，宫 2×2。
- 每行、每列、每宫内 4 个符号各出现一次。
- 符号 id：`0..3`；展示用主题映射（emoji/SF Symbol/色块）。
- 预填若干格（随难度增加：预填变少或逻辑更深）；玩家填空格。

### 4.1 难度曲线（grade 2）

| 关卡段 | 预填约 | 说明 |
|--------|--------|------|
| 1–10 | 10–8 | 入门，主题轮换起步 |
| 11–30 | 8–6 | 常规 |
| 31–60 | 6–5 | 稍难 |
| 61+ | 5–4 | 渐难，仍保持 4×4（二年级不升 6×6，除非以后改配置） |

种子：`hash(family_code, grade, level)` 保证同关可复现。

### 4.2 主题轮换（4C）

`themeIndex = (level - 1) % themes.count`  
例：`shapes` / `fruit` / `animals` / `vehicles`（各 4 个符号资源）。

## 5. 技术方案

### 5.1 内容与后端

- `content/extension_activities.json`：活动元数据（id、标题、年级支持）。
- 表 `extension_progress`：`activity_id, grade, highest_cleared_level, updated_at`（家庭自用单学习者）。
- API：
  - `GET /extension/activities`
  - `GET /extension/sudoku/level?grade=&level=` → 返回 puzzle（givens、size、theme、symbols）
  - `POST /extension/sudoku/clear` → `{level}` 校验可选（客户端提交 board 或仅信任通关信号；**建议服务端用同种子复算校验**）
  - `GET /extension/progress`
- 生成器：纯 Python 挖空 + 唯一解检查（4×4 穷举可行）。

### 5.2 iOS

- 首页卡片「头脑拓展」
- `ExtensionHubView`：活动列表
- `SudokuGameView`：4×4 格、符号板、点选；拖放为增强
- 本地可缓存 progress，以服务端为准
- 胜利：轻反馈 + 「下一关」

### 5.3 Out of Scope（本期）

- 6×6 / 9×9 盘面
- 强激励排行榜、连胜强迫
- 英语拓展活动
- 丰富爸爸&朋友旁白（8B）
