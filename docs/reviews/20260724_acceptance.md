## 2. 顶尖前端设计师视角

### 问题 / 缺陷

1. 首页信息架构清晰，但学科卡片与下方链接的视觉权重接近，家长区入口偏「藏」，符合预期，但星级入口可更像主路径之一。  
2. 练习页选项按钮样式统一，但长应用题题干在横屏下的行宽未做专门阅读优化。  
3. 主题色（奶油底 + 叶绿）避开了常见 AI 紫/奶油衬赤陶套路，方向正确；系统圆体依赖较强，品牌字体尚未定制。

### 改进建议

- 为「课后巩固 / 薄弱 / 习惯」增加简单插画或动效（进入练习时 1 个过渡即可）。  
- 解析区用固定「爸爸」语气标签，强化人设存在感。  
- iPad 横屏双栏：左题右解析（答完后）。

## 3. 顶尖视觉交互设计师视角

### 问题 / 缺陷

1. 提交后到「下一题」依赖二次点击，二年级用户可接受，但可增加短促正确动效降低挫败。  
2. 手写需再输入确认，认知步骤偏多（有意为之的安全降级，但应在 UI 上解释「为什么还要打字」）。  
3. 听力仅播放一次按钮，缺「慢速再听」；拼读无跟读，符合 MVP 默认，但需在题干旁标注「点选即可」。

### 改进建议

- 答对：轻量缩放/星级闪一下（2～3 处有意动效即可）。  
- 手写面板标题改为「先写一写，再把数字填进框里」。  
- 家长门禁失败时给出更温和文案，避免「失败」字样吓到孩子误触。
