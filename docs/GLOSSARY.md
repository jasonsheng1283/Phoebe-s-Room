# GLOSSARY — 术语表

## 产品与空间

| 术语 | 定义 |
|------|------|
| Phoebe's Room | 本产品名称；AI 辅助学科知识点强化训练空间。 |
| 学习空间 / Room | 学习者的个人训练环境（进度、画像、练习记录所在之处）。 |

## 学科学段

| 术语 | 定义 |
|------|------|
| 学段 | 小学 / 初中 / 高中等阶段划分。 |
| 年级 | 学段内年级；**MVP 锁定小学二年级**。 |
| 学科 | **MVP：数学、英语**；长期可扩展语文及更多学科。 |
| 知识点 | 可被单独诊断、练习与评估的最小教学单元；首期**不绑定教材版本**，按通识知识点组织。 |
| 知识图谱 | 知识点之间的前置、并列、进阶关系网络。 |
| 掌握度 | MVP 以**星级**展示某知识点掌握水平（具体星数规则在实现时定义，须可解释）。 |

## 内容与题目

| 术语 | 定义 |
|------|------|
| 种子题 / 典型题 | 人工精选或导入的基准题目，作为题库质量锚点。 |
| 相似题生成 | 基于种子题，由 AI 生成同知识点、同难度带的变式题。 |
| 题目审核 | 对 AI 生成题进行自动检查（及必要时人工确认）后再进入可练习池。 |
| 题目解析 | 作答后给出的解题说明与错因提示（MVP 必有）。 |
| 选择题 | 数学等学科从选项中点选答案。 |
| 填空题 | 需输入或手写填入关键答案。 |
| 应用题 | 情境叙述类数学题；MVP 优先结构化关键答案可自动判。 |
| 单词拼读 | 英语题型：围绕单词音形对应的听/选/拼练习（跟读评分可为增强）。 |
| 听力题 | 英语题型：播放音频后作答。 |
| 口语陪练 | 独立模块：跟读与少量问答，孩子开口录音，云端识别后给予鼓励、示范与星级。 |
| 跟读 | 听示范后口头复述目标词/句，可回放自己的录音。 |
| 口语问答 | 按剧本回答简单口头问题（非自由闲聊）。 |

## 训练闭环

| 术语 | 定义 |
|------|------|
| 课后巩固 | 针对近期学习内容的练习场景。 |
| 薄弱专项 | 针对掌握度偏低知识点的集中强化。 |
| 日常习惯 | 短时、可坚持的每日练习入口。 |
| 诊断 | 通过少量题目定位薄弱知识点（MVP 可简化）。 |
| 强化训练 | 针对薄弱点进行有计划的练习与讲解。 |
| 反馈 | 批改结果 + 题目解析。 |
| 复盘 | 对一段时间练习结果的总结与错因归类。 |
| 再测 | 训练后的掌握度验证。 |
| 间隔复习 | 基于遗忘曲线或规则的定期重练；**MVP 不做完整引擎**，以薄弱专项 + 错题再练替代。 |

## 角色

| 术语 | 定义 |
|------|------|
| 学习者 | 使用产品进行训练的儿童（MVP：小学二年级，家庭自用）。 |
| 家长 | 监护人；MVP 可通过**家长页**查看进度摘要（需门禁）。 |
| 家长门禁 | 防止孩子误入家长页的简单验证（如计算题/密码，实现时定）。 |
| AI 陪练 | 人设为「**爸爸 & 朋友**」：温和陪伴、鼓励为主，负责解析语气与激励文案；首期交互以做题为主，非自由闲聊。 |
