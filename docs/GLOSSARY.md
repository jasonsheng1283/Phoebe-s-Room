## 产品与空间

| 术语 | 定义 |
|------|------|
| Phoebe's Room | 本产品名称；AI 辅助学科知识点强化训练空间。 |
| 学习空间 / Room | 学习者的个人训练环境（进度、画像、练习记录所在之处）。 |

## 学科学段

| 术语 | 定义 |
|------|------|
| 学段 | 小学 / 初中 / 高中等阶段划分（具体年级映射待确认）。 |
| 学科 | 如语文、数学、英语、物理、化学、生物、历史、地理等（首期范围待确认）。 |
| 知识点 | 可被单独诊断、练习与评估的最小教学单元。 |
| 知识图谱 | 知识点之间的前置、并列、进阶关系网络。 |
| 掌握度 | 对某知识点当前能力水平的量化或分级表示（算法与量表待定）。 |

## 训练闭环

| 术语 | 定义 |
|------|------|
| 诊断 | 通过少量题目或对话，定位薄弱知识点。 |
| 强化训练 | 针对薄弱点进行有计划的练习与讲解。 |
| 反馈 | AI 或系统对作答结果的即时解释、纠错与提示。 |
| 复盘 | 对一段时间练习结果的总结与错因归类。 |
| 再测 | 训练后的掌握度验证。 |
| 间隔复习 | 基于遗忘曲线或规则的定期重练安排。 |

## 角色

| 术语 | 定义 |
|------|------|
| 学习者 | 使用产品进行训练的儿童/青少年（主用户）。 |
| 家长 | 监护人角色，可查看进度与报告（权限边界待确认）。 |
| 辅导者 | 教师或家教等可选角色（是否纳入 MVP 待确认）。 |
| AI 陪练 | 负责出题、讲解、引导与激励的智能助手。 |
