# 讨论：全站「阳光小房间 / 软糖色」UI 重设计

> 日期：2026-07-24  
> 状态：已确认，执行中

## 背景

现有界面功能可用，但视觉偏「清淡系统感」：简单 `RoomTheme`、系统 List、题干以纯文字为主，题内图形为程序化 Path，对二年级小朋友吸引力不足。

## 确认结论

| 项 | 结论 |
|----|------|
| 范围 | 1A 全站统一（首页、选 KP、模式、做题、口语、拓展/数独、星级、家长区） |
| 题内图形 | 2B 静态插画（Asset Catalog）；`drag_place` 用场景底图，槽位仍在图下列表 |
| 风格 | 阳光小房间 + 软糖色 |
| 动效 | 克制：选中轻弹、答对 bounce、答错轻晃；无连击/音效轰炸 |
| 相似题 | 继承种子题插画字段，不自动生图 |

## 非目标

- 不改抽题/批改业务逻辑
- 不做图上像素级 drop
- 不改 App Icon
- 不加 BGM / 排行榜式激励
