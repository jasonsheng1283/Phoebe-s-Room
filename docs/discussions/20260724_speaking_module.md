## 1. 我方复述（请确认）

在现有 Phoebe's Room（二年级英语、做题为主）之上，新增一个**英语口语陪练**能力：孩子对着 iPad 说英语，系统给予反馈/引导，人设仍贴近「爸爸 & 朋友」，并与现有知识点/星级体系可衔接（衔接深度待定）。

这与当前已有的「单词拼读 / 听力（点选 + TTS）」不同：口语模块的核心是**开口说**，而不仅是听选。

---

## 2. 疑问清单（请逐条简答）

### A. 场景与目标

1. **首期口语场景**更偏向哪几类？（可多选排序）  
   - 跟读单词/句子（听示范 → 再说）  
   - 看图/看提示说一句话  
   - 简单问答对话（AI 提问，孩子回答）  
   - 自由话题闲聊（一般不建议首期）
2. **单次时长**期望？（如 5～10 分钟）
3. 从哪里进入？独立「口语」入口，还是挂在英语学科下的第四模式？

### B. 评测与反馈

4. 反馈要到什么程度？  
   - 仅鼓励 + 示范再听  
   - 有「是否大致正确」的判定  
   - 要发音打分 / 星级（需语音识别或第三方评测）
5. 是否必须**离线可用**，还是可走云端语音识别 + LLM？
6. 错了时：直接给正确示范，还是先引导再示范？

### C. 内容与范围

7. 首期内容范围：限定现有英语知识点（短元音、常见词、颜色/动物等），还是单独一套口语剧本？
8. 是否与**星级掌握度**联动（口语练习也涨星）？

### D. 技术与合规

9. 是否接受调用云端 **Speech-to-Text / 发音评测 API**（麦克风音频出域）？
10. 家长页是否要能看到口语练习次数/时长？

### E. 分期

11. MVP 口语是否接受「先跟读 + 录音回放 + AI 文字点评」，发音高精度打分放二期？

## 3. 建议默认（可改）

| 项 | 建议 |
|----|------|
| 入口 | 英语学科下新增「口语陪练」 |
| 首期形态 | 跟读单词/短句为主 + 少量固定问答 |
| 评测 | 云端 STT + LLM 温和点评；不做复杂百分制发音分 |
| 人设 | 爸爸 & 朋友；禁止无边界闲聊 |
| 星级 | 口语次数计入相关知识点，规则从简 |
| 技术 | SwiftUI 录音 → 后端代理 STT/LLM；Key 不进客户端 |
