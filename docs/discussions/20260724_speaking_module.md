## 1. 已确认复述

在 Phoebe's Room 首页增加**独立入口「口语陪练」**（不挂在数学习题路径下）。首期做：

1. **跟读**单词/短句（听示范 → 孩子说 → 可回放自己的录音）  
2. **少量固定问答**（AI/剧本提问 → 孩子口头回答）  
3. 反馈：**鼓励 + 正确示范再听 + 星级评分**  
4. 允许云端语音识别（麦克风音频可出域，经服务端代理）  
5. MVP 交付完整闭环：跟读 + 录音回放 + AI 文字点评 + 星级（不做无边界闲聊）

与现有「拼读/听力点选」区分：口语核心是**开口说**。
