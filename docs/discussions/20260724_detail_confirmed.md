## 1. 产品方回复

| # | 主题 | 结论 |
|---|------|------|
| 1 | 题型 | 数学：选择、填空、应用题；英语：单词拼读、听力 |
| 2 | 作答 | **点选为主**，并支持 **输入 / 手写** |
| 3 | 掌握度 | **星级** |
| 4 | 家长页 | **要**（进 MVP） |
| 5 | 发布节奏 | **先 TestFlight**，再考虑正式上架 |
| 6 | 客户端技术 | **SwiftUI**（取代此前 Expo 建议） |

## 2. 复述（请确认无误）

1. 数学练习覆盖选择 / 填空 / 应用题；英语侧重单词拼读与听力理解。  
2. iPad 交互以点选为主，填空等场景支持键盘输入与手写。  
3. 知识点掌握度用星级展示。  
4. MVP 含家长进度视图。  
5. 交付先走 TestFlight 家庭内测。  
6. 客户端采用原生 **SwiftUI**；后端仍建议轻量 API + 服务端 LLM 代理。

## 3. 对计划的影响

| 项 | 影响 |
|----|------|
| 听力 | 需音频资源或 TTS；英语练习流含播放控件 |
| 拼读 | 需发音示范 + 跟读/选音等交互（具体题模在内容设计中细化） |
| 手写 | SwiftUI + PencilKit（或等价）纳入作答组件 |
| 应用题 | 题干可能较长；解析与批改规则需支持多步/关键作答（可先简化为填关键空或选结论） |
| 家长页 | F-024 升为 MVP P0/P1，需家长门禁（防孩子误入） |
| SwiftUI | 工程为 Xcode iOS/iPadOS App，非 Expo |

## 4. 仍开放（可用默认方案开工）

| ID | 问题 | 计划默认（可改） |
