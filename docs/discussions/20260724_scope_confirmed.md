## 2. 更新后的需求复述（请再扫一眼）

1. 首期做一个给自家孩子用的 iPad 应用（面向 App Store），聚焦小学二年级数学与英语。  
2. 产品以**做题**为核心，每题有解析；AI 语气像「爸爸又像朋友」。  
3. 练习服务三种意图：课后巩固、薄弱专项、日常习惯。  
4. 内容以种子题库为锚，AI 生成相似题并经检查审核后进入练习；按知识点组织，暂不跟某一版教材死绑。  
5. 可调用云端 LLM API；技术栈由实现计划建议，你确认后再开发。

## 4. 仍开放、建议尽快拍板的问题

### 高优先级（影响 MVP 设计）

1. **题型**：二年级数学 / 英语首期要哪些？（例：数学选择/填空/口算；英语选词/看图选义/听音——听力是否首期？）  
2. **作答方式**：iPad 上以点选为主，还是需要手写/键盘输入？  
3. **掌握度展示**：星级 / 百分比 / 三档熟练，你更倾向哪种？  
4. **日常习惯**：期望单次多久（如 10～15 分钟）、是否要温和提醒，是否要「连续天数」？  
5. **家长**：首期要不要家长页？只要你自己看后台数据也行？  
6. **语言**：App 界面默认中文？英语练习的题干/解析是否中英混排？

### 中优先级（可计划里给默认方案）

7. 间隔复习是否进 MVP，还是先做错题本 + 薄弱专项即可？  
8. 激励：要不要积分/徽章？（建议 MVP 仅「完成反馈 + 掌握进步」）  
9. 儿童安全：每日时长上限、家长门禁、禁止闲聊——是否全部要硬开关？  
10. 模型供应商偏好（OpenAI / 其他）与是否已有 API Key？  
11. App Store：是否必须首版就过审上架，还是先 TestFlight 家庭内测？

## 5. 技术方向建议（写入计划，待你许可后执行）

面向 **iPad + App Store**：

- **客户端推荐**：Expo（React Native）——一套代码、适合平板布局、便于 TestFlight / App Store。  
- **后端推荐**：轻量 API（如 Node 或 Python）负责题库、进度、鉴权，并作为 **LLM 调用代理**（Key 不放客户端）。  
- **数据**：云端数据库存学习记录与题库；首期单家庭账号模型即可。  

若你更倾向原生 SwiftUI，也可在许可前改口，计划会相应调整。
