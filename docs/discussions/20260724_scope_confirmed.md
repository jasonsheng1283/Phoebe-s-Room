## 2. 更新后的需求复述（请再扫一眼）

1. 首期做一个给自家孩子用的 iPad 应用（面向 App Store），聚焦小学二年级数学与英语。  
2. 产品以**做题**为核心，每题有解析；AI 语气像「爸爸又像朋友」。  
3. 练习服务三种意图：课后巩固、薄弱专项、日常习惯。  
4. 内容以种子题库为锚，AI 生成相似题并经检查审核后进入练习；按知识点组织，暂不跟某一版教材死绑。  
5. 可调用云端 LLM API；技术栈由实现计划建议，你确认后再开发。
