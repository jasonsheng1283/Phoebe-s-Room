# 隐私政策草案（TestFlight / 上架用）

> 状态：草案，非正式法律意见。上架前请按实际情况修订并由你确认。

## 我们是谁

Phoebe's Room（「菲比的房间」）是面向家庭自用的儿童学科学习辅助应用，由应用提供者运营。

## 我们收集什么

- 学习相关数据：练习记录、正误、知识点掌握度（星级）、练习时长会话信息
- 设备与诊断：为修复崩溃可能收集的技术日志（若启用）
- **不**以广告追踪为目的收集数据；MVP **无**第三方广告 SDK

## 如何使用数据

- 提供练习批改、解析、掌握度展示与家长摘要
- 可选调用云端大模型 API 生成相似题或润色解析时，题目/提示内容可能发送至模型服务商（需在设置中配置 Key；密钥仅存服务端）

## 儿童隐私

本应用主要面向儿童学习者，由家长监护使用。请勿在题目或昵称中填写多余个人敏感信息。家长区设有简单门禁。

## 数据存储与传输

- 学习记录存储于应用后端数据库
- 网络传输使用你配置的服务地址；生产环境应使用 HTTPS

## 你的选择

家庭自用场景下，可联系应用提供者导出或删除学习数据。

## 联系方式

请填写：你的联系邮箱。

## 变更

政策更新时会在此文档与应用内适当位置提示。
