## 一句话定位

**Phoebe's Room** 是一个面向儿童与青少年的 AI 辅助学科知识点强化训练空间，目标使用周期贯穿小学到高中，帮助学习者在长期学习路径中查漏补缺、巩固掌握、建立可持续的学习习惯。

## 产品愿景

- 用 AI 做「懂孩子、懂进度」的陪练（人设：**爸爸 & 朋友**），而不是简单刷题机。
- 覆盖多学科、多学段，知识点可追踪、可复盘、可进阶；实现上分期推进。
- 陪伴式成长：从小学启蒙到高中备考，数据与能力模型可持续累积。
- 首期为**家庭自用**；家长可适度看见进度，但不打扰孩子的专注练习（家长深度仍有开放项）。

## MVP 已确认范围（2026-07-24）

| 维度 | 结论 |
|------|------|
| 使用对象 | 首期家庭自用 |
| 学段 / 年级 | 小学二年级 |
| 学科 | 数学、英语 |
| 主场景 | 课后巩固、薄弱专项、日常习惯 |
| 主设备 | iPad（计划上架 App Store） |
| 交互形态 | **做题为主**，须有题目解析 |
| AI 人设 | 「爸爸 & 朋友」 |
| 内容策略 | **题库为主**；基于典型题借助 AI 生成相似题并检查审核；以知识点组织，**暂不绑定教材版本** |
| 模型 | 可调用云端模型 API；数据可走云端 |
| 技术栈 | 无既定偏好（由实现计划给出建议后确认） |

## 核心用户

| 角色 | 诉求 | 状态 |
|------|------|------|
| 学习者（主用户，约小学二年级） | 巩固知识点、即时反馈、可持续的小习惯 | 已确认首期画像 |
| 家长 | 了解进度与薄弱点（深度待定） | 部分确认 |
| 教师/辅导者 | — | **首期不做** |

## 当前阶段约束

- 已完成需求关键项确认与文档更新；**未获明确开发许可前不进入业务代码开发**。
- 产品名 / 仓库名：`Phoebe-s-Room`（Phoebe's Room）。
- 长期愿景跨小学→高中，但 MVP 仅二年级数学 + 英语。

## 非目标（首期）

- 完整替代学校课程或系统网课平台
- 大规模 C 端商业化 / 多家庭运营中台
- 无监督的开放式自由聊天
- 绑定具体教材版本
- 教师端 / 班级管理
- 以对话式教学为主的产品形态（首期做题为主）

## 成功标准（MVP）

- 二年级数学、英语可按知识点完成：选题练习 → 批改 → 解析 → 掌握度可见
- 能支持课后巩固、薄弱专项、日常习惯三类入口（具体交互可分期）
- iPad 上体验可用，架构面向后续 App Store 上架
- 题库种子题 + AI 相似题生成具备可审核链路
