## 一句话定位

**Phoebe's Room** 是一个面向儿童与青少年的 AI 辅助学科知识点强化训练空间，目标使用周期贯穿小学到高中，帮助学习者在长期学习路径中查漏补缺、巩固掌握、建立可持续的学习习惯。

## 产品愿景

- 用 AI 做「懂孩子、懂进度」的陪练（人设：**爸爸 & 朋友**），而不是简单刷题机。
- 覆盖多学科、多学段，知识点可追踪、可复盘、可进阶；实现上分期推进。
- 陪伴式成长：从小学启蒙到高中备考，数据与能力模型可持续累积。
- 首期为**家庭自用**；MVP **含家长进度页**（门禁防误入），不打扰孩子专注练习。

## MVP 已确认范围（2026-07-24）

| 维度 | 结论 |
|------|------|
| 使用对象 | 首期家庭自用 |
| 学段 / 年级 | 小学二年级 |
| 学科 | 数学、英语 |
| 主场景 | 课后巩固、薄弱专项、日常习惯 |
| 主设备 | iPad |
| 发布节奏 | **先 TestFlight**，再 App Store |
| 交互形态 | **做题为主**，须有题目解析 |
| 题型 | 数学：选择、填空、应用题；英语：单词拼读、听力 |
| 作答 | 点选为主，支持输入 / 手写 |
| 掌握度 | **星级** |
| 家长 | MVP **包含**家长进度视图 |
| AI 人设 | 「爸爸 & 朋友」 |
| 内容策略 | 题库为主 + AI 相似题检查审核；知识点组织；暂不绑教材 |
| 模型 | 云端模型 API |
| 客户端技术 | **SwiftUI** |
| 后端 | 轻量 API + 服务端 LLM 代理（见计划） |

## 核心用户

| 角色 | 诉求 | 状态 |
|------|------|------|
| 学习者（小学二年级） | 巩固知识点、即时反馈、小习惯 | 已确认 |
| 家长 | 查看进度 / 薄弱 / 练习摘要 | MVP 含家长页 |
| 教师/辅导者 | — | 首期不做 |

## 当前阶段约束

- 已获开发许可并完成后端 + SwiftUI 源码主干；iOS 需在 Mac 本地编译；TestFlight 待开发者账号。
- 产品名 / 仓库名：`Phoebe-s-Room`（Phoebe's Room）。

## 非目标（首期）

- 完整网课平台、多家庭商业化、教师端
- 自由闲聊、教材版本绑定
- 完整间隔复习引擎、重激励排行榜
- 应用题深度过程分、强制跟读评分（可作后续增强）

## 成功标准（MVP）

- 数学三类题型、英语拼读与听力均可完成：练习 → 批改 → 解析 → **星级**可见
- 三入口可用；家长页可用（有门禁）
- SwiftUI iPad 体验可用；可走 TestFlight
- 种子题 + AI 相似题具备检查链路
