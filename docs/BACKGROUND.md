# BACKGROUND — 产品定位与背景

> 状态：讨论中（Draft）  
> 最近更新：2026-07-24  
> 讨论存档：`docs/discussions/20260724_kickoff.md`

## 一句话定位

**Phoebe's Room** 是一个面向儿童与青少年的 AI 辅助学科知识点强化训练空间，目标使用周期贯穿小学到高中，帮助学习者在长期学习路径中查漏补缺、巩固掌握、建立可持续的学习习惯。

## 产品愿景（草案）

- 用 AI 做「懂孩子、懂进度」的陪练，而不是简单刷题机。
- 覆盖多学科、多学段，知识点可追踪、可复盘、可进阶。
- 陪伴式成长：从小学启蒙到高中备考，数据与能力模型可持续累积。
- 家长/教师可适度参与：看见进度与薄弱点，但不打扰孩子的专注练习。

## 核心用户（待确认）

| 角色 | 可能诉求 | 待确认点 |
|------|----------|----------|
| 学习者（主用户） | 高效巩固知识点、获得即时反馈、有成就感 | 年龄段启动优先级、设备端 |
| 家长 | 了解进度、薄弱点、学习时长与习惯 | 干预深度、报告频率 |
| 教师/辅导者（可选） | 布置/推荐练习、查看班级或个人掌握度 | 是否纳入 MVP |

## 当前已知约束

- 项目尚处**需求讨论与文档建制**阶段，未获许可前不进入功能开发。
- 产品名 / 仓库名：`Phoebe-s-Room`（Phoebe's Room）。
- 学段跨度大（小学→高中），需在知识体系、交互复杂度、内容合规上做分期设计。

## 非目标（草案，待确认）

以下内容默认**暂不作为首期目标**，除非讨论中明确纳入：

- 完整替代学校课程或系统网课平台
- 大规模 C 端商业化运营中台（若首期是家庭私用/小范围试用）
- 无监督的开放式自由聊天（需安全与内容边界）

## 成功标准（草案，待确认）

- 学习者能按知识点完成强化训练闭环：诊断 → 练习 → 反馈 → 复盘 → 再测
- 跨学段知识图谱可扩展，不因学段切换推倒重来
- 家长能看懂「掌握了什么 / 还差什么」，而不是只有刷题数量
