## 1. 背景与目标

在做题闭环之外，增加开口说英语的陪练能力，服务二年级家庭自用场景，人设「爸爸 & 朋友」。

### 成功标准

- 首页有独立「口语陪练」入口
- 可完成跟读与少量问答全流程：示范 → 录音 → 回放 → 点评 → 星级
- 音频经服务端做 STT（及可选 LLM 点评）；Key 不进客户端
- 口语结果可反映到英语知识点星级；家长摘要可见口语次数/时长

## 2. 用户与场景

- 学习者：跟读单词/短句；回答简单口头问题
- 家长：在家长页看到口语练习摘要
- 非场景：自由闲聊、开放社交、离线高精度评测

## 3. 范围

### In Scope

- 独立入口与口语会话 UI（SwiftUI / iPad）
- 跟读题、问答剧本（种子内容）
- 录音、本地回放、上传音频
- 服务端 STT + 鼓励文案/点评 + 星级（1～5）
- TTS/系统语音示范再听
- 与英语知识点星级、家长摘要联动
- 麦克风权限与隐私说明更新

### Out of Scope（本轮）

- 无主题自由聊天
- 第三方专业音素级发音引擎（可作为后续增强）
- 真人外教视频

## 5. 功能说明

### 5.1 入口与会话

- 首页独立卡片「口语陪练」
- 会话含若干跟读项 + 少量问答项（可配置，默认约 5～8 轮，约 5～10 分钟）

### 5.2 跟读

- 展示目标词/句 → 播放示范 → 按住/点击录音 → 可回放 → 提交评测

### 5.3 问答

- 展示问题（可语音读出）→ 孩子回答录音 → 回放 → 提交

### 5.4 评测与星级

- 服务端：音频 → STT 文本 → 与期望文本比对 + LLM 生成爸爸&朋友语气点评 → 映射星级
- 客户端展示：鼓励语、示范再听按钮、星级

### 5.5 数据

- 口语 attempt 记录；更新相关 `knowledge_point` 星级
- 家长 summary 增加口语字段

## 6. AI / 语音与安全

- 云端 STT + LLM，经后端代理
- 禁止闲聊；仅当前剧本轮次
- 儿童麦克风数据最小化保留策略（可配置是否存音频文件；MVP 可只存转写与评分）

## 7. 非功能

- iPad；需麦克风权限
- 网络依赖云端 STT
- 更新隐私草案：麦克风与语音出域说明

## 8. 开放问题（有默认）

| ID | 问题 | 默认 |
