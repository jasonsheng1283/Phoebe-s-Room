## 1. 背景与目标

把功能可用但偏系统感的界面，升级为面向小学二年级的清新可爱「阳光小房间 / 软糖色」体验；题内图形以静态插画呈现。

成功标准：全站风格统一；选项触控友好；有插画的题正确显示；缺图不崩；无成瘾连击激励。

## 2. 用户与场景

- 主用户：二年级学习者（iPad）
- 次要：家长（同色板、偏安静）

## 3. 范围

### In Scope

- 设计系统（色板、背景、入口卡、主按钮、选项芯片、反馈卡、进度点、题干图）
- 全站页面皮肤：首页 / 选 KP / 模式 / 练习 / 口语 / 拓展数独 / 星级 / 家长
- 题目 `image_asset`；`drag_place.interaction.background_asset`
- Asset Catalog 插画资源

### Out of Scope

- 图上像素级 drop、相似题自动生图、App Icon、BGM、连击激励

## 4. 需求条目

1. 作为孩子，我能在明亮可爱的首页一眼找到数学/英语/口语/拓展入口。
2. 作为孩子，做题时选项够大，答对有轻庆祝，答错不刺眼。
3. 作为孩子，图形题能看到可爱插画场景再拖标签作答。
4. 作为家长，进入家长区后界面仍清晰但不抢眼。

## 5. 非功能

- 动效克制；不诱导沉迷
- 插画缺失时优雅降级
- 相似题继承种子插画字段
