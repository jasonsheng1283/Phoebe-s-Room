## 1. 背景与目标

### 问题

二年级阶段知识点需要反复巩固；薄弱点不清、反馈不及时、习惯难坚持。家庭需要一个可在 iPad 上使用的、以做题+解析为核心的 AI 陪练空间，并为后续学段扩展留好结构。

### 目标

首期（家庭自用）交付小学二年级**数学 + 英语**的 SwiftUI iPad App：做题为主、有解析、人设「爸爸 & 朋友」；支持选择/填空/应用题与单词拼读/听力；点选+输入/手写；星级掌握度；家长页；内容为题库+相似题；先 TestFlight。

### 成功标准（MVP）

- 数学三类题型、英语拼读与听力可完成：练习 → 批改 → 解析 → 星级可见
- 三入口可用；家长页有门禁且可看摘要
- 种子题 + AI 相似题检查链路可用
- 可进行 TestFlight 内测

## 2. 用户与场景

### 用户

- **主用户**：学习者（小学二年级，家庭自用）
- **次要用户**：家长（MVP 含家长进度页）
- **不做**：教师 / 班级

### 关键场景

1. **课后巩固** → 练习 → 解析  
2. **薄弱专项**（低星级知识点）→ 集中练习  
3. **日常习惯** → 短时练习  
4. **家长**查看进度 / 薄弱 / 时长摘要  

### 非场景

- 完整网课、自由闲聊、多家庭 SaaS、教师布置、教材死绑、排行榜

## 3. 范围

### 3.1 In Scope（MVP）

- SwiftUI iPad 客户端
- 学习者档案；数学/英语知识点目录
- 题型：数学选择/填空/应用题；英语单词拼读/听力
- 作答：点选为主，输入与手写
- 题库 + AI 相似题生成与自动检查
- 批改 +「爸爸 & 朋友」解析
- 三入口；星级掌握度
- 家长页（门禁）
- 云端 API + LLM 代理
- TestFlight 构建路径

### 3.2 Out of Scope（MVP）

- 全学段全学科、教师端、对话教学主形态
- 正式公网上架作为硬门禁（先 TestFlight）
- 完整间隔复习引擎、积分排行榜
- 应用题过程分、强制跟读评分（增强项）

## 5. 功能说明

### 5.1 学习档案

- 家庭自用单学习者；年级默认二年级

### 5.2 知识体系

- 二年级数学 / 英语知识点树；稳定 ID；不绑教材版本文案
- 数学：以人教版二年级上下册为通识骨架的**技能级**目录；条目含 `semester`（`upper` / `lower`）
- 英语：保持现有拼读 / 听力 / 常见词目录（可无 semester）

### 5.3 题库与相似题

- 种子题含题型、音频文案（听力）、答案、解析骨架
- AI 相似题 → 自动检查 → 入池

### 5.4 训练练习流

- 科目 → **选择知识点（全部 / 多选）** → 模式 → 展示 → 作答（点选/输入/手写）→ 批改 → 解析
- 无题知识点可见但不可选（待练习）
- 数学：选择、判断（对/错）、拖放排序与图上定位
- 英语：拼读、听力（播放控件）；跟读评分非必须

### 5.5 掌握度与习惯

- **星级**展示与更新
- 日常习惯：默认 10～15 分钟；连续天数轻量（见讨论默认）

### 5.6 家长视图

- 门禁进入；进度、薄弱（低星）、练习时长摘要
